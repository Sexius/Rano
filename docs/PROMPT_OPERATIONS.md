\# RANO Operations Prompt Template



목표:

\[배포, 환경변수, 키 교체, 설정 변경 등 운영 작업 한 줄]



작업 유형:

운영 작업 (코드 수정이 필요하면 그 범위만 최소화)



프로젝트 전제:

\- 이 프로젝트는 RANO이다.

\- frontend는 React, backend는 Spring Boot이다.

\- frontend는 backend API만 호출한다.

\- 외부 데이터 API 호출과 API 키 사용은 backend에서만 처리한다.

\- docs/ARCHITECTURE.md, docs/WORKFLOW.md, docs/DEPLOYMENT.md를 반드시 따른다.



반드시 지킬 규칙:

\- 원인 분석형 디버깅으로 불필요하게 확장하지 않는다.

\- 운영 절차를 먼저 정리한다.

\- 코드 수정이 필요하면 최소 범위만 수정한다.

\- 관련 없는 구조 변경 금지

\- 작업 후 설정 반영 여부를 검증한다.



작업 절차:

1\. 현재 운영 상태 요약

2\. 필요한 설정 변경 식별

3\. 변경 절차 정리

4\. 필요한 최소 작업 수행

5\. 검증

6\. 변경 내용 보고



출력 형식:

\- 작업 목적

\- 변경 절차

\- 수정/설정 항목

\- 검증 방법

\- 남은 이슈
