# 어비스 체이서 입력 검산 메모

## 목적
- 현재 허수아비 계산기는 실측 로그에 잘 맞고 있다.
- 하지만 `P.ATK 계수`가 비정상적으로 크게 튀는 것으로 보아,
  계산식 문제뿐 아니라 입력 누락 또는 세트 중복 해석 문제도 같이 의심해야 한다.
- 이 문서는 **현재까지 수집한 장비 설명/상태창 기준으로 어떤 항목이 맞고, 어떤 항목이 흔들리는지** 정리한 메모다.

## 현재 기준
- 직업: 어비스 체이서
- 대상: 훈련장 허수아비
- 크기: 중형
- 종족: 무형 추정
- DEF: 0
- 실측 로그:
  - 체이싱 브레이크 본체 1타 `88,068,600`
  - 자동 데프트 스탭 1타 `130,860,159`
  - 수동 데프트 스탭 1타 `126,247,790`

## 상태창 기준 주요 수치
- 맨몸 P.ATK `61`
- P.ATK `260` (`어비스 슬레이어 OFF`)
- P.ATK `290` (`어비스 슬레이어 ON`)
- 변동 캐스팅 감소 `35%`
- 글로벌 쿨타임 감소 `60%`
- 근접 물리 데미지 `294%`
- 원거리 물리 데미지 `68%`
- 모든 속성 적 물리 데미지 `80%`
- 각 종족 물리 데미지 `37%`
- 체이싱 브레이크 데미지 증가 `100%`
- 데프트 스탭 데미지 증가 `89%`
- 어비스 대거 데미지 증가 `14%`
- 페이탈 메나스 데미지 증가 `30%`
- 유도공격 `31%`

## 잘 맞는 항목

### 1. 변동 캐스팅 감소 35%
장비 설명 기준 합:
- 요르 아머 `10%`
- 글레이시아 가드 `10%`
- 요르 글러브 `5%`
- 요르 링+글러브 세트 `10%`

합계:
- `35%`

판정:
- 상태창과 정확히 일치

### 2. 유도공격 31%
장비 설명 기준 합:
- 천공 체이싱 대거 `5%`
- 숲의 마력구(밀리) `26%`

합계:
- `31%`

판정:
- 상태창과 정확히 일치

### 3. 어비스 대거 데미지 증가 14%
장비 설명 기준 합:
- 데프트 브레이커 펜던트 쉐도우 기본 `8%`
- 3제련당 `+2%`, +10 기준 `+6%`

합계:
- `14%`

판정:
- 상태창과 정확히 일치

### 4. 페이탈 메나스 데미지 증가 30%
장비 설명 기준 합:
- 쉐도우 체이서 스톤(걸칠것) `15%`
- 상단+중단 세트 `15%`

합계:
- `30%`

판정:
- 상태창과 정확히 일치

### 5. 데프트 스탭 데미지 증가 89%
장비 설명 기준 합:
- 천공 룬 크라운 제련 보너스 `15%`
- 천공 룬 크라운 C등급 `15%`
- 천공 룬 크라운 + 체이싱 대거 세트 `45%`
- 데프트 브레이커 이어링 기본 `8%`
- 데프트 브레이커 이어링 3제련당 보너스, +10 기준 `6%`

합계:
- `89%`

판정:
- 상태창과 정확히 일치

## 의심 항목

### 1. P.ATK 260 / 290
실측 확인:
- 맨몸 상태 → `61`
- 풀세팅 + `어비스 슬레이어 ON` → `290`
- 풀세팅 + `어비스 슬레이어 OFF` → `260`
- 오른쪽 악세 해제 → `245`
- 방패 해제 → `257`

즉 다음 두 항목은 상태창에 정확히 반영된다.
- 장비를 전부 벗어도 `기본 P.ATK 61`이 남는다
- 오른쪽 악세 총 P.ATK 기여 `-15`
- 방패 총 P.ATK 기여 `-3`
- 어비스 슬레이어 버프 기여 `+30`

즉 장비 설명만으로 계산한 추정치를 다시 보면:
- 버프 ON 기준 대략 `169`
- 버프 OFF 기준 대략 `139`

주요 합산 추정:
- 투구 `5`
- 무기 `15`
- 갑옷 `40`
- 걸칠것 `10`
- 신발 `25`
- 방패 `3`
- 악세 오른쪽 `15`
- 악세 왼쪽 `10`
- 쉐도우 및 세트 `16`
- 어비스 슬레이어 `30`

합계:
- 버프 ON 기준 대략 `169`
- 버프 OFF 기준 대략 `139`

차이:
- 상태창 `290` (버프 ON)
- 상태창 `260` (버프 OFF)
- 추정 차이 `+121` 정도

의심 원인:
- 장비 설명에 없는 **기본 P.ATK 산출식**이 실제로 존재함 (`61`)
- 특성 스탯 `POW/CON/BaseLv`가 상태창 P.ATK에 직접 반영
- 패시브/숨은 보너스 누락 가능

판정:
- 가장 큰 입력 미확정 항목

### 2. 글로벌 쿨타임 감소 60%
장비 설명 기준 합:
- 투구 `10%`
- 무기 `10%`
- 요르 아머 `5%`
- 요르 망토 `15%`
- 요르 링+글러브 세트 `10%`
- 쉐도우 체이서 스톤(중단) `1%`

합계:
- `51%`

차이:
- 상태창 `60%`
- 추정 차이 `+9%`

실측 확인:
- 왼쪽 악세 해제 → `50%` (`-10`, 악세 세트 글쿨과 정확히 일치)
- 요르 망토 해제 → `60%` (`0`, 설명상의 글쿨 15%가 상태창 변화로 잡히지 않음)
- 의상 중단 해제 → `55%` (`-5`, 설명 텍스트의 1%와 다르게 실제 상태창은 5% 감소)

의심 원인:
- 요르 망토 글쿨은 현재 상태창 표기 방식과 다르게 처리될 가능성
- 의상 중단 스톤은 단독 1%가 아니라 숨은 세트/묶음 효과를 같이 포함할 가능성
- 추가 패시브/숨은 세트효과 누락 가능

### 3. 체이싱 브레이크 데미지 증가 100%
장비 설명 기준 합:
- 천공 룬 크라운 제련 보너스 `15%`
- 천공 체이싱 대거 기본 `15%`
- 천공 체이싱 대거 4제련당 보너스, +12 기준 `21%`
- 천공 체이싱 대거 11제련 `15%`
- 천공 체이싱 대거 C등급 `10%`
- 천공 체이싱 대거 B등급 `10%`
- 데프트 브레이커 펜던트 기본 `8%`

합계:
- `94%`

차이:
- 상태창 `100%`
- 추정 차이 `+6%`

실측 확인:
- 데프트 브레이커 펜던트 쉐도우 해제 → `86%` (`-14`, 설명 합과 정확히 일치)
- 천공 체이싱 대거 해제 → `29%` (`-71`, 무기 쪽 기여분과 정확히 일치)

의심 원인:
- 세트/쉐도우/숨은 옵션 누락
- 현재 남은 `29%`는 대략 `크라운 15 + 펜던트 8 + 미확인 6`으로 해석 가능
- 상태창 표기 방식 차이

### 4. 모든 속성 적 물리 데미지 80%
현재 설명 합산으로는 `80%`보다 조금 높게 나오는 경향이 있다.

주요 출처 후보:
- 스윗 드롭스의 알 `7%`
- 천공 룬 크라운 A등급 `10%`
- 요르 아머+망토 `15%`
- 요르 아머+부츠 `15%`
- 요스터 해결사 카드 + 요스코푸스 수호사 카드 세트 `15%`
- 악세 인챈트 피지컬 파워 2개 `10%`
- 의상 상단+하단 `15%`
- 소드 마스터 아머+슈즈 `5%`
- 데프트 브레이커 이어링+펜던트+인피니티 웨폰 `3%`
- 설화 묘력(인텔리전스) `3%`

실측 확인:
- 요르 부츠 해제 → `65%` (`-15`, 아머+부츠 세트와 정확히 일치)
- 요르 망토 해제 → `50%` (`-30`, 아머+망토 15 + 카드 세트 15로 해석 가능)
- 의상 걸칠것 해제 → `80%` (`0`, 의상 걸칠것 자체는 모든 속성 물리와 무관)

의심 원인:
- 큰 방향에서는 입력이 맞다
- 다만 일부 세트효과를 중복 집계했을 가능성은 여전히 있음

### 5. 모든 종족 물리 데미지 37%
이제는 거의 설명 가능하다.

주요 출처 후보:
- 요르 종족 세트 `15%` (망토+부츠 / 3셋 중 1회만 집계되는 것으로 가정)
- 의상 하단+걸칠것 `15%`
- 스윗 드롭스의 알 `7%`

합계:
- `37%`

판정:
- `종족 37%`는 이제 거의 설명 가능
- 요르 종족 세트는 2개가 동시 집계되지 않고 1회만 반영된다고 보는 해석이 가장 자연스럽다

### 6. 표시 ATK +1234
장비 설명 기준 flat ATK도 상당 부분 설명 가능하다.

주요 출처 후보:
- 투구 `18`
- 무기 `350`
- 갑옷 `330`
- 걸칠것 `50`
- 신발 `20`
- 악세 `120`
- 쉐도우 `114`
- 스윗 드롭스의 알 `20`

합계:
- `1022`

차이:
- 상태창 `1234`
- 미확정 `212`

의심 원인:
- 상태창 우측 ATK에는 단순 장비 ATK 외에 시스템 제련/무기 계산 일부가 추가 포함될 수 있음
- 현재 계산기는 `무기/제련/오버제련`을 별도 버킷으로 분리하고 있으므로, 상태창 우측 수치와 1:1 비교는 주의가 필요함
- 그럼에도 `212` 정도는 아직 숨은 입력 또는 집계 규칙 차이로 남아 있음

### 6. ATK% 138
이번 실험으로 `ATK%` 쪽도 상당 부분 설명 가능해졌다.

주요 출처 후보:
- 투구 `8%`
- 천공 체이싱 대거 D등급 `5%`
- 요르 아머 계열 `33%`
- 요스코푸스 수호사 카드 `순수 STR 120 → +24%`
- 요르 망토 `16%`
- 요르 부츠 `22%`
- 악세 좌우 기본 `20%`
- 쉐도우 `8%`

합계:
- `136%`

차이:
- 상태창 `138%`
- 추정 차이 `+2%`

판정:
- `ATK%`는 이제 거의 설명 가능
- 남은 미확정치는 `2%` 수준으로, 계산기 오차의 주원인이라고 보기 어렵다

## 현재 판단

### 확실한 것
- `변동 캐스팅`, `유도공격`, `어비스 대거`, `페이탈 메나스`, `데프트 스탭`은 입력이 비교적 신뢰 가능하다.

### 가장 큰 불확실성
- `추가 P.ATK를 제외한 기본 P.ATK 산식`
- `글로벌 쿨타임 감소`
- `표시 ATK +1234 집계 방식`
- `체이싱 브레이크 증뎀`
