# 어비스 체이서 입력 검산 메모

## 목적
- 현재 허수아비 계산기는 실측 로그에 잘 맞고 있다.
- 하지만 `P.ATK 계수`가 비정상적으로 크게 튀는 것으로 보아,
  계산식 문제뿐 아니라 입력 누락 또는 세트 중복 해석 문제도 같이 의심해야 한다.
- 이 문서는 **현재까지 수집한 장비 설명/상태창 기준으로 어떤 항목이 맞고, 어떤 항목이 흔들리는지** 정리한 메모다.

## 현재 기준
- 직업: 어비스 체이서
- 대상: 훈련장 허수아비
- 크기: 중형
- 종족: 무형 추정
- DEF: 0
- 실측 로그:
  - 체이싱 브레이크 본체 1타 `88,068,600`
  - 자동 데프트 스탭 1타 `130,860,159`
  - 수동 데프트 스탭 1타 `126,247,790`

## 상태창 기준 주요 수치
- P.ATK `260`
- 변동 캐스팅 감소 `35%`
- 글로벌 쿨타임 감소 `60%`
- 근접 물리 데미지 `294%`
- 원거리 물리 데미지 `68%`
- 모든 속성 적 물리 데미지 `80%`
- 각 종족 물리 데미지 `37%`
- 체이싱 브레이크 데미지 증가 `100%`
- 데프트 스탭 데미지 증가 `89%`
- 어비스 대거 데미지 증가 `14%`
- 페이탈 메나스 데미지 증가 `30%`
- 유도공격 `31%`

## 잘 맞는 항목

### 1. 변동 캐스팅 감소 35%
장비 설명 기준 합:
- 요르 아머 `10%`
- 글레이시아 가드 `10%`
- 요르 글러브 `5%`
- 요르 링+글러브 세트 `10%`

합계:
- `35%`

판정:
- 상태창과 정확히 일치

### 2. 유도공격 31%
장비 설명 기준 합:
- 천공 체이싱 대거 `5%`
- 숲의 마력구(밀리) `26%`

합계:
- `31%`

판정:
- 상태창과 정확히 일치

### 3. 어비스 대거 데미지 증가 14%
장비 설명 기준 합:
- 데프트 브레이커 펜던트 쉐도우 기본 `8%`
- 3제련당 `+2%`, +10 기준 `+6%`

합계:
- `14%`

판정:
- 상태창과 정확히 일치

### 4. 페이탈 메나스 데미지 증가 30%
장비 설명 기준 합:
- 쉐도우 체이서 스톤(걸칠것) `15%`
- 상단+중단 세트 `15%`

합계:
- `30%`

판정:
- 상태창과 정확히 일치

### 5. 데프트 스탭 데미지 증가 89%
장비 설명 기준 합:
- 천공 룬 크라운 제련 보너스 `15%`
- 천공 룬 크라운 C등급 `15%`
- 천공 룬 크라운 + 체이싱 대거 세트 `45%`
- 데프트 브레이커 이어링 기본 `8%`
- 데프트 브레이커 이어링 3제련당 보너스, +10 기준 `6%`

합계:
- `89%`

판정:
- 상태창과 정확히 일치

## 의심 항목

### 1. P.ATK 260
장비 설명만으로 계산한 추정치는 대략 `169` 수준이다.

주요 합산 추정:
- 투구 `5`
- 무기 `15`
- 갑옷 `40`
- 걸칠것 `10`
- 신발 `25`
- 방패 `3`
- 악세 오른쪽 `15`
- 악세 왼쪽 `10`
- 쉐도우 및 세트 `16`
- 어비스 슬레이어 `30`

합계:
- 대략 `169`

차이:
- 상태창 `260`
- 추정 차이 `+91`

의심 원인:
- 장비 설명에 없는 **기본 P.ATK 산출식**이 있음
- 특성 스탯 `POW/CON/BaseLv`가 상태창 P.ATK에 직접 반영
- 패시브/숨은 보너스 누락 가능

판정:
- 가장 큰 입력 미확정 항목

### 2. 글로벌 쿨타임 감소 60%
장비 설명 기준 합:
- 투구 `10%`
- 무기 `10%`
- 요르 아머 `5%`
- 요르 망토 `15%`
- 요르 링+글러브 세트 `10%`
- 쉐도우 체이서 스톤(중단) `1%`

합계:
- `51%`

차이:
- 상태창 `60%`
- 추정 차이 `+9%`

의심 원인:
- 추가 패시브/숨은 세트효과 누락
- 일부 장비 옵션이 설명 분해 과정에서 빠졌을 가능성

### 3. 체이싱 브레이크 데미지 증가 100%
장비 설명 기준 합:
- 천공 룬 크라운 제련 보너스 `15%`
- 천공 체이싱 대거 기본 `15%`
- 천공 체이싱 대거 4제련당 보너스, +12 기준 `21%`
- 천공 체이싱 대거 11제련 `15%`
- 천공 체이싱 대거 C등급 `10%`
- 천공 체이싱 대거 B등급 `10%`
- 데프트 브레이커 펜던트 기본 `8%`

합계:
- `94%`

차이:
- 상태창 `100%`
- 추정 차이 `+6%`

의심 원인:
- 세트/쉐도우/숨은 옵션 누락
- 상태창 표기 방식 차이

### 4. 모든 속성 적 물리 데미지 80%
현재 설명 합산으로는 `80%`보다 조금 높게 나오는 경향이 있다.

주요 출처 후보:
- 천공 룬 크라운 A등급 `10%`
- 요르 아머+망토 `15%`
- 요르 아머+부츠 `15%`
- 요스터 해결사 카드 + 요스코푸스 수호사 카드 세트 `15%`
- 악세 인챈트 피지컬 파워 2개 `10%`
- 의상 상단+하단 `15%`
- 소드 마스터 아머+슈즈 `5%`
- 데프트 브레이커 이어링+펜던트+인피니티 웨폰 `3%`
- 설화 묘력(인텔리전스) `3%`

의심 원인:
- 같은 세트 효과를 중복 집계했을 가능성
- 상태창에는 일부 그룹이 다른 라인으로 분산될 가능성

### 5. 모든 종족 물리 데미지 37%
현재 설명 합산으로는 `37%`보다 높게 잡힌다.

주요 출처 후보:
- 요르 망토+부츠 `15%`
- 요르 아머+망토+부츠 `15%`
- 의상 하단+걸칠것 `15%`

단순 합:
- `45%`

차이:
- 상태창 `37%`

의심 원인:
- 같은 계열 세트 효과가 중복 적용되지 않을 가능성
- 상태창 집계 규칙 차이

## 현재 판단

### 확실한 것
- `변동 캐스팅`, `유도공격`, `어비스 대거`, `페이탈 메나스`, `데프트 스탭`은 입력이 비교적 신뢰 가능하다.

### 가장 큰 불확실성
- `P.ATK`
- `글로벌 쿨타임 감소`
- `종족/속성 증뎀`
- `체이싱 브레이크 증뎀`

## 다음 우선순위
1. 상태창 P.ATK의 기본 산출식 존재 여부 확인
2. 글쿨 60%를 만드는 누락 옵션 추적
3. 종족/속성 세트효과가 실제로 중복 집계되는지 재검토
4. 체이싱 브레이크 +100%의 남은 6% 출처 찾기
