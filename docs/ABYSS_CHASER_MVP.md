# 어비스 체이서 MVP 정의

## 목적
전 직업을 한 번에 완성하지 않고, 어비스 체이서 1직업만 먼저 실제로 맞는 데미지 계산 흐름을 만든다.

이 문서는 아래 3가지를 고정하기 위한 기준 문서다.

1. 어떤 스킬을 먼저 검증할지
2. 어떤 장비군을 먼저 계산형 데이터로 만들지
3. 어떤 순서로 인게임 실험과 코드 보정을 반복할지

## MVP 범위

### 직업
- 어비스 체이서

### 우선 장비군
- 천공 세트
- 요르 세트

### 우선 슬롯
- 무기
- 갑옷
- 걸칠것
- 신발
- 상단 투구
- 악세서리 좌/우

## 1차 검증 대상 스킬

현재 코드와 데이터에서 먼저 잡기 쉬운 후보는 아래 3개다.

1. 체이싱 브레이크 (`ABC_CHASING_BREAK`)
2. 어비스 스퀘어 (`ABC_ABYSS_SQUARE`)
3. 데프트 스탭 (`ABC_DEFT_STAB`)

이 3개를 먼저 이유:
- 이미 코드 상에 키가 존재함
- 어비스 체이서 전용 기술군으로 묶기 쉬움
- 단일/범위/조건부 보정 검증에 적합함

## 지금 바로 필요한 데이터

- Base Lv

- STR

### 전투 조건
- 대상 방어력

- 대상이 보스인지 여부

### 장비 효과

- 제련 수치
- 등급
- 근거리/원거리 증뎀
- 보스/종족/크기 증뎀
- 크리 데미지
- 방무
- 스킬별 증뎀
- 세트 효과

## 아이템 DB 작업 기준

### 전체 아이템 DB
계속 넓게 가져가도 된다.

- 이름
- 부위
- 설명
- 이미지
- 제련 가능 여부

### 계산형 아이템 DB
지금은 어비스 체이서 + 천공/요르 세트 관련 장비부터 깊게 만든다.

필수 필드:
- `baseAtk`
- `atk`, `atkP`
- `pAtk`
- `rangeP`, `meleeP`
- `bossP`, `raceP`, `sizeP`, `elementP`
- `critDmgP`
- `ignoreDef`
- `skillDamage`
- `perRefine`
- `gradeBonus`
- `setEffects`

## 검증 순서

### 1단계. 스킬 하나를 고른다
가장 먼저 `체이싱 브레이크`부터 시작한다.

### 2단계. 장비를 최소화한다
천공/요르 기준 세팅 한 벌만 먼저 잡는다.

### 3단계. 인게임 실험값을 모은다
가능하면 아래 조건을 고정한다.

- 버프/소비템 최소화
- 같은 맵/같은 몬스터
- 같은 스킬 레벨
- 같은 제련/카드/옵션
- 치명타/비치명타 구분

### 4단계. 계산기와 비교한다
- 게임값
- 계산값
- 차이
- 추정 원인

### 5단계. 공식 보정
한 번에 완벽하게 맞추려 하지 말고,
오차 원인을 하나씩 줄인다.

## 이번 주 실제 작업 순서

1. 체이싱 브레이크 실험 표 채우기
2. 천공/요르 세트 장비 데이터 추출
3. `SkillLogic.ts`의 어비스 체이서 임시 공식 제거/정리
4. 어비스 체이서 전용 계산 함수 초안 만들기
5. 계산 결과와 인게임 값 비교

## 메모

지금 단계에서는 "전 직업 지원"보다 "어비스 체이서 하나라도 믿고 쓸 수 있게 만들기"가 우선이다.
