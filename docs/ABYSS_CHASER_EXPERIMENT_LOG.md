# 어비스 체이서 실험 로그

## 사용 방법
인게임에서 한 번 실험할 때마다 아래 형식으로 한 줄씩 추가한다.

같은 스킬이라도 조건이 다르면 별도 행으로 기록한다.

## 공통 규칙
- 가능하면 버프/소모품 조건을 명확히 적는다.
- 대상 몬스터가 같아야 비교가 쉽다.
- 크리티컬 여부를 따로 적는다.
- 장비 변경 시 어떤 부위를 바꿨는지 적는다.

## 우선 채워야 할 시나리오

### 체이싱 브레이크
- 버프 없음 / 비크리
- 버프 없음 / 크리
- 천공 세트
- 천공 + 요르 세트
- 제련 차이

### 어비스 스퀘어
- 동일 몬스터 기준 기본값
- 보스 대상 여부 비교
- 장비 증뎀 반영 전후

### 데프트 스탭
- 기본 위치
- 조건부 보너스 발생 상황

## 오차 원인 후보 체크리스트
- 스킬 기본 퍼센트가 다름
- 타수가 다름
- 방어력 반영 방식이 다름
- 보스/종족/크기 증뎀이 곱연산인지 합연산인지 다름
- 제련 보너스 누락
- 세트 효과 누락
- 스킬 전용 증뎀 누락
- 크리티컬 배율 누락

## 현재 확보한 관측값

### 조건
- 직업: 어비스 체이서
- Base Lv: 256
- 활성 버프: 어비스 슬레이어 Lv 10
- 주요 장비: 천공 + 요르 세트, 의상/쉐도우 포함

### 체이싱 브레이크 사용 로그
- 로그에 서로 다른 대미지 2종이 반복됨
- 관측값 A: `88,068,600`
- 관측값 B: `130,860,159`
- 현재 해석:
  - 관측값 A = 체이싱 브레이크 본체 후보
  - 관측값 B = 자동 발동 데프트 스탭 후보

### 데프트 스탭 단독 사용 로그
- 관측값: `126,247,790`
- 5회 반복 확인
- 현재 해석:
  - 데프트 스탭 단독 사용 시 `1타 = 126,247,790`
  - 총 5히트

- 단독 데프트 스탭과 체이싱 브레이크 연동 데프트 스탭의 차이는 추가 검증 필요
