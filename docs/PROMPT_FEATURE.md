\# RANO Feature Prompt Template



목표:

\[구현할 기능 한 줄]



프로젝트 전제:

\- 이 프로젝트는 RANO이다.

\- frontend는 React, backend는 Spring Boot이다.

\- frontend는 backend API만 호출한다.

\- 외부 데이터 API 호출과 API 키 사용은 backend에서만 처리한다.

\- docs/ARCHITECTURE.md, docs/WORKFLOW.md, docs/DEPLOYMENT.md를 반드시 따른다.



반드시 지킬 규칙:

\- 먼저 현재 구조와 영향 범위를 요약한다.

\- 필요한 파일만 수정한다.

\- 관련 없는 리팩토링 금지

\- 기존 동작을 깨지 않게 한다.

\- 기능 구현 후 반드시 빌드/실행으로 검증한다.



작업 절차:

1\. 기능 요구사항 요약

2\. 영향 파일 식별

3\. 구현 계획 정리

4\. 필요한 코드만 수정

5\. 검증

6\. 변경 파일과 이유 보고



출력 형식:

\- 기능 요약

\- 영향 파일

\- 구현 내용

\- 변경 파일

\- 검증 결과

\- 주의사항
