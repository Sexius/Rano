# ATK 시뮬 참고 메모

## 참고 출처
- 원본글: https://www.inven.co.kr/board/ro/1959/393
- 사용법 정리: https://www.inven.co.kr/board/ro/1951/4179

## 왜 참고하는가
- 구형 KRO ATK 시뮬은 `ATK 버킷`을 따로 나눠서 본다.
- 지금 어비스 체이서 계산기에서도 이 구조가 가장 도움이 된다.
- 다만 4차 직업, 특성 스탯, 최신 장비/쉐도우/스톤은 예전 글과 다를 수 있으므로 실측 로그를 우선한다.

## 현재 계산기에 바로 도움이 되는 핵심 규칙

### 1. 스테이터스 ATK
- 스탯으로만 오르는 ATK
- 계산기에서 자동 계산 대상으로 둔다.

### 2. 무기 ATK
- 무기 설명창의 기본 공격력만 해당
- 카드, 인챈트, 제련 특수옵션으로 붙는 ATK은 여기에 넣지 않는다.

### 3. 제련 ATK / 오버제련 ATK
- 무기 제련으로 기본적으로 붙는 ATK
- 안전제련 초과분은 오버제련 ATK으로 별도 취급
- 현대 서버에서 레벨 5 무기 계수는 추가 검증 필요

### 4. STR 추가 ATK
- 무기 ATK에 STR 기반으로 붙는 추가 기여분
- 원거리 무기면 DEX 기준으로 바뀐다.

### 5. 장비 ATK
- 무기 기본 ATK 외에 설명문에서 `ATK + n` 형태로 붙는 거의 모든 값
- 카드, 인챈트, 장비 옵션, 버프, 소비 아이템, 쉐도우 웨폰 제련 ATK도 여기로 들어간다.

### 6. 랜덤 ATK
- 무기 데미지 편차 영역
- 단일 로그값보다 평균값 비교가 더 안전하다.

### 7. 마스터리 ATK
- 수련류 스킬이 주는 고정 공격력
- 일반 장비 ATK와 분리해서 보는 편이 안전하다.

## 현재 프로젝트에 적용하는 원칙

### 원칙 1
- 인벤 글은 구조 참고용이다.
- 실측 로그와 다르면 실측 로그를 우선한다.

### 원칙 2
- 계산 함수는 최소한 아래 버킷을 분리한다.
  - statusAttack
  - weaponAttack
  - refineAttack
  - overRefineAttack
  - equipmentAttack
  - masteryAttack
  - traitAttack

### 원칙 3
- `ATK%`, `근접/원거리`, `크기`, `종족`, `속성`, `보스`, `스킬 증뎀`은 같은 그룹으로 뭉개지지 않게 한다.

### 원칙 4
- 허수아비 실험은 단일값보다 평균값, 최소/최대 범위를 같이 본다.
