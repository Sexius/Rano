# RANO Debug Prompt Template

목표:
[현재 발생한 버그나 이상 동작 한 줄]

프로젝트 전제:
- 이 프로젝트는 RANO이다.
- frontend는 React, backend는 Spring Boot이다.
- frontend는 backend API만 호출한다.
- 외부 데이터 API 호출과 API 키 사용은 backend에서만 처리한다.
- docs/ARCHITECTURE.md, docs/WORKFLOW.md, docs/DEPLOYMENT.md를 반드시 따른다.

반드시 지킬 규칙:
- 먼저 현재 상태와 증상을 요약한다.
- 바로 수정하지 말고 원인 가설을 1~3개로 정리한다.
- 필요한 경우 웹 검색으로 공식 문서와 신뢰 가능한 자료를 먼저 찾는다.
- 추측만으로 수정하지 않는다.
- 한 번에 한 가지 원인만 수정한다.
- 관련 없는 리팩토링, 구조 변경, 파일 이동은 금지한다.
- 수정 후 반드시 빌드, 실행, 로그, 네트워크 결과로 검증한다.

작업 절차:
1. 현재 상태 요약
2. 영향 파일 식별
3. 원인 가설 정리
4. 필요 시 웹 검색으로 근거 확보
5. 가장 가능성 높은 원인 1개만 수정
6. 검증
7. 변경 파일과 이유 보고

출력 형식:
- 증상
- 원인 가설
- 검색 근거
- 수정 내용
- 변경 파일
- 검증 결과
- 남은 문제
